# 架空史图志 · 历史地图工坊

在浏览器里绘制架空历史地图的网页工具，不需要安装任何东西。

## 功能
- **陆海 / 地貌 / 森林**：笔刷画大陆、海洋、湖泊；平原、草原、丘陵、山地、雪山、沙漠、沼泽、冻土；阔叶林、针叶林、热带雨林、竹林、白桦林、疏林灌木。
- **河流**：手绘，从源头到入海口逐渐变宽；可拖动节点修改。
- **国家 / 行政区划制度**：每个国家选一套历史制度（秦郡县、汉州郡县、隋州县、唐道州县、宋路州县、元行省、明清省府县、日本律令制、蒙古千户制、笈多、萨珊、阿契美尼德、南洋曼陀罗、晚期罗马、拜占庭军区、欧洲封建、英格兰郡制、帝俄、哈里发、奥斯曼），各级名称统一、下辖数量按历史比例；笔刷或油漆桶涂色；一键自动划分三级；可只看省、道或府。国名与行政区名固定显示在区域最宽处。
- **国体与爵位**：帝国（皇室）、王国（王室）、汗国、苏丹国、哈里发国、沙皇国、幕府，大公国、选侯国、公国、边疆伯国、侯国、独立伯国（伯爵领）、雅尔领、男爵领（贵族），共和国、商业共和国、神权国、部落；任何国家都可设宗主成为附庸，地图上以宗主色斜纹显示。
- **中国历代分封**：西周五等爵（公侯伯子男）、汉郡国并行（诸侯王国、列侯国）、西晋宗王（大国、次国、小国、郡公、县侯）、唐藩镇与羁縻府州、元宗王兀鲁思与投下、明藩王与土司、清三藩与札萨克旗、日本幕藩、朝贡藩属；宗室封国自动沿用宗主姓氏（如「齐王刘氏」）。
- **国家档案**：国体、君主称号、建国年与国祚、首都、国教、面积（真实模板按平方公里估算）、各级行政区数量与名单、城市、军队构成、统治家族（君主、配偶、继承人）、宗主与封国、可随机生成的国家背景。
- **国力排名**：领土 65% ＋ 军力 35%（兵力 × 兵种系数），可按综合、领土、军力排序，附庸可按一半计入宗主。
- **家族**：家族列表、概况（宗教、文化、居城、影响力、战功）、族谱树、人物卡（属性、特质、亲属、传记），地图上可显示家族旗帜。
- **画风**：鲜明（游戏地图风）/ 羊皮纸（手绘风）；城市可选插画图标或简洁圆点。
- **智能笔刷**：彩笔、国家、行政区画笔可锁定他国（他区）、以河为界、以山为界、以海为界，油漆桶同样遵守；开启锁定时预览实际涂色范围，按住 Alt 临时解除。
- **AI 智能修边**：画完一笔可选择让算法把边界修整成真实疆界的样子（贴河、沿山脊、自然曲折、去碎块），Ctrl+Z 可撤回。
- **选中国家高亮**：点领土、国名或列表即可高亮整片领土（压暗周围、金色光晕），飞地用虚线圈标出，可一键定位到全国或任一飞地。
- **城市**：首都、大城、中城、小城、村镇、要塞、港口、关隘。
- **按文明随机命名**：华夏、草原、东瀛、天竺、波斯、南洋、罗马、希腊、日耳曼、斯拉夫、北欧、凯尔特、阿拉伯、英格兰。 所有名字（含西方文明）都以中文显示：政体词意译（王国、公国、哈里发国…），地名按新华社习惯音译（-burg 堡、-grad 格勒…）。
- **军队**：步兵类（轻步兵、重步兵、长枪兵、刀盾兵、弓兵、弩兵、禁军、民兵）、骑兵类（轻骑兵、重骑兵、骑射手、枪骑兵、骆驼骑兵、战象）、战车、攻城器械、水军；进军箭头；战役/遗迹/寺庙/矿产标记。
- **线条**：国界、行政界、道路、航线、长城、战线。
- **文字**：海名、地区名、标题框。
- **亚洲模板**（默认）：真实亚洲地理（海岸、山脉、沙漠、森林、河流、湖泊、气候），不含国家，直接用彩笔涂色。
- **欧洲模板**：西欧、东欧、北欧、南欧，加北非地中海沿岸、土耳其与西亚、阿拉伯半岛大部分（兰勃特圆锥投影）。
- **高精度海岸线**：真实地理模板使用 Natural Earth 1:1000万矢量海岸，放大也清晰。
- **天汉历626年示例**：同一张亚洲地图加上完整架空势力、城市、家族。
- **随机大陆**：大陆、半岛、海湾、内陆湖、海岛与群岛、山脉、河流；按纬度、风带、雨影计算 14 种气候带，并据此铺设地貌和森林。
- **气候图层**：可显示气候图例，也可以手动涂改气候带。
- **电脑键盘操作**：WASD/方向键移动地图（Shift 加速），Q/E 缩放，数字键 1–0 切换工具，[ ] 调笔刷，Z 橡皮，G 油漆桶，Ctrl/⌘+S 保存，Home 全图，Tab 隐藏面板，I 国家档案，O 国力排名，? 查看全部快捷键。
- **参考图描图**、撤销/重做、自动保存（浏览器内）、JSON 存档、PNG 导出。

## 技术
纯静态 HTML + Canvas，无构建步骤。海岸线数据来自 Natural Earth（world-atlas）。
