# 架空史图志 · 历史地图工坊

在浏览器里绘制架空历史地图的网页工具，不需要安装任何东西。

## 功能
- **陆海 / 地貌 / 森林**：笔刷画大陆、海洋、湖泊；平原、草原、丘陵、山地、雪山、沙漠、沼泽、冻土；阔叶林、针叶林、热带雨林、竹林、白桦林、疏林灌木。
- **河流**：手绘，从源头到入海口逐渐变宽；可拖动节点修改。
- **国家 / 行政区**：笔刷或油漆桶涂色；自动划分行政区、自动生成城市；可移动国名、调整字号和角度。
- **城市**：首都、大城、中城、小城、村镇、要塞、港口、关隘。
- **按文明随机命名**：华夏、草原、东瀛、天竺、波斯、南洋、罗马、希腊、日耳曼、斯拉夫、北欧、凯尔特、阿拉伯、英格兰。
- **军队**：步兵、骑兵、弓弩、器械、水军；进军箭头；战役/遗迹/寺庙/矿产标记。
- **线条**：国界、行政界、道路、航线、长城、战线。
- **文字**：海名、地区名、标题框。
- **预设「天汉历626年」**：真实欧亚地理 + 架空势力。也可以随机生成新世界。
- **参考图描图**、撤销/重做、自动保存（浏览器内）、JSON 存档、PNG 导出。

## 技术
纯静态 HTML + Canvas，无构建步骤。海岸线数据来自 Natural Earth（world-atlas）。
